## 鱼亦称是做什么的？

鱼亦称面向**鱼塘现场收鱼、逐桶过磅、按车整理和事后核账**的场景。把原本写在本子上的毛重、皮重、鱼种和规格整理成电子流水，方便回查、算价和打印留存。

重量由现场人员手动输入。它不是电子秤，也不代替双方现场确认读数。

## 能帮现场做哪些事？

- **连续记桶**：选择鱼种、规格、皮重，输入毛重；确认一桶后继续下一桶，自动计算净重。
- **整理流水**：按鱼种、规格分开查看，每 10 桶一组，保留毛重、皮重和净重，便于回头核对。
- **分车分仓**：查看车辆与各仓重量，专业版可同时记录多辆车。
- **补填单价**：现场价格没谈好，可以先保存称重记录，之后在历史记录中补填单价、查看金额。
- **修正皮重**：皮重保留一位小数；双方最终确认后，可按鱼种和规格统一修改对应记录的皮重。
- **打印留存**：生成含鱼种规格汇总、车辆合计和逐桶明细的 PDF，供核账、分享或打印。
- **双方核对**：买卖双方使用不同账号，各自独立记录，通过邀请加入同一场核对，查看对应桶号的差异，再各自检查、修正。

核对功能用于辅助发现差异，不代表系统能发现所有错误。双方都漏记同一桶，或都输入了同一个错误数字，仍需要现场核实。未同步、待核对也不等于数据一致。

## 简单版与专业版怎么选？

- **简单版**：一次记录一车鱼，适合连续录入为主的现场。
- **专业版**：增加多车辆管理，适合一次同时记录多车鱼。

两种模式围绕相同的称重步骤设计。切换前请保存当前记录；不要假设切换模式会自动搬迁所有本机数据。

## 第一次使用

1. 从[官网](https://yijiankj.com.cn/)选择适合手机的入口。Android 下载 APK；iPhone 使用 Safari 打开网页试用版，不能安装 APK。
2. 选好鱼种、规格和皮重，输入一桶毛重，点击“确定 / 下一桶”。
3. 通过流水核对记录。称完保存本次，补填单价，核对数量、重量和金额后再导出 PDF。

安装来源、当前版本、校验值和使用帮助均以官网公布的信息为准。不要为了安装或访问而关闭手机安全防护、忽略浏览器证书警告。
